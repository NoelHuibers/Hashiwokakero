Hashi for F-Droid

Hashi, the daily bridges logic puzzle, has its own F-Droid repository: the Android app built from its source code without any proprietary code, signed by its developer. Updates arrive in F-Droid, Droid-ify, Neo Store and other F-Droid clients.

Add to F-Droid

Or add it by hand: in F-Droid, Settings, Repositories, "+", then paste

{{REPO_URL}}?fingerprint={{FINGERPRINT}}

or scan the code of the repository's page.

Repository: {{REPO_URL}}
Fingerprint (SHA-256): {{FINGERPRINT}}

The same APKs are on the GitHub releases. They are signed with another key than the app on Google Play, so neither updates the other: to switch, uninstall the other one first (with an account, your results and streak stay).
